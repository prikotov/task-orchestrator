# TASK-research-coding-agents-summary: Сводная таблица и итоговые рекомендации

## 1. Concept and Goal (Концепция и Цель)
### Story (Job Story)
> **Job Story:** Когда мы завершили исследование 14 CLI-агентов кодинга, я хочу видеть сводную таблицу с рейтингами и рекомендациями, чтобы принять обоснованное решение о том, каких агентов подключать к нашей системе ролей в первую очередь.

### Goal (Цель по SMART)
Создать единую сводную таблицу `docs/research/coding-agents-summary.md` со всеми 14 агентами. Ранжировать по пригодности для сабагент-интеграции. Выделить Top-3 кандидатов для приоритетной интеграции. Итоговые рекомендации по адаптации нашей системы ролей и скиллов.

## 2. Context and Scope (Контекст и Границы)
*   **Где делаем:** `docs/research/coding-agents-summary.md`
*   **Текущее поведение:** 14 индивидуальных отчётов в `docs/research/coding-agents/`
*   **Границы (Out of Scope):** новые исследования агентов, код интеграции

## 3. Requirements (Требования, MoSCoW)
### 🔴 Must Have (Обязательно)
- [ ] Сводная таблица с колонками: агент, 10 критериев (оценка +/~/-), вердикт
- [ ] Группировка по категориям (open source / проприетарный)
- [ ] Ранжирование агентов по степени пригодности для сабагент-интеграции
- [ ] Top-3 кандидата для приоритетной интеграции с обоснованием
- [ ] Рекомендации по адаптации системы ролей и скиллов для мультиагентной среды

### 🟡 Should Have (Желательно)
