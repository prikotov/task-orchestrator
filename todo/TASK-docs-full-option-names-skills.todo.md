## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)

В таблицах параметров скиллов оркестрации (формат «Параметр | Сокращение | Назначение | По умолчанию») и в текстах/примерах используются краткие ключи CLI: `-s`, `-m`, `-t`, `-o`, `-r`. AI-агенты, читая эти инструкции, формируют вызовы `watch-subagent.sh` с краткими ключами. Краткое имя контринтуитивно: оно не говорит само за себя, требует двойного сопоставления «сокращение → полное имя → смысл», и агенты чаще ошибаются с полными именами, чем с краткими. Решение владельца (2026-11-24): уйти от использования сокращений в документации — в таблицах и примерах оставлять только полные имена ключей (`--soft-timeout`, `--hard-timeout`, `--stall-timeout`, `--output`, `--role-file`).

### Варианты или путь решения (Solution Sketch)

Один вариант, механический: во всех затронутых файлах документации заменить краткие ключи на полные и убрать колонку «Сокращение» из таблицы параметров. Скрипт `watch-subagent.sh` НЕ меняется: краткие ключи остаются поддерживаемым интерфейсом (обратная совместимость существующих вызовов), уходим только от их использования в инструкциях для агентов.

### Ожидаемый результат (Expected Result)

Агент, читая любой из затронутых файлов, видит только полные имена опций и формирует вызовы `watch-subagent.sh` исключительно с ними. Таблица параметров в `run-subagent/SKILL.md` не содержит колонки «Сокращение». Проверка `grep` по затронутым файлам не находит кратких ключей. Человек видит это по диффу: ни одного `-s`/`-m`/`-t`/`-o`/`-r` в качестве ключа CLI в инструкциях и примерах.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)

> Как AI-агент (тимлид или исполнитель), запускающий сабагентов по инструкциям скиллов, я хочу видеть в документации только полные имена опций CLI, чтобы формировать вызовы `watch-subagent.sh` без ошибок и двойного сопоставления «сокращение → полное имя».

### Цель по SMART (Goal)

В четырёх файлах (`run-subagent/SKILL.md`, `run-subagent/README.md`, `task-via-subagents/SKILL.md`, `epic-via-subagents/SKILL.md`) заменить все краткие ключи CLI на полные имена и убрать колонку «Сокращение» из таблицы параметров; критерий: `grep`-проверка по четырём файлам не находит кратких ключей как ключей CLI, `make md-links` и `validate-language` зелёные, правки опубликованы в `main` через PR.

## 7. Риски и зависимости (Risks and Dependencies)

- Риск 1: grep-паттерн может зацепить нецелевые совпадения (например, дефис в тексте или опцию `-o text,files` внутри кодового блока чужого формата) — смягчается ручной сверкой списка замен из инвентаризации (план, шаг 1) перед правками.
- Риск 2: часть упоминаний кратких ключей может быть осмысленной ссылкой на интерфейс (например, «принимает три таймаута: `-s` (soft), `-m` (hard)`») — такие места переписываются на полные имена с сохранением смысла, а не удаляются.
- Зависимостей от других задач нет; задача выполняется после слияния PR #498 (актуальные таблицы таймаутов), но текстово от него не зависит — при конфликте база ветки актуализируется.
