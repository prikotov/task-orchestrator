# TASK-docs-frameworks-epic-evergreen: Закрепить evergreen-режим эпика EPIC-research-agent-frameworks-comparison

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
- Эпик `EPIC-research-agent-frameworks-comparison` формально закрыт по DoD («все задачи выполнены»), но новые агент-оркестраторы появляются постоянно: эпик уже дважды переоткрывался (2026-08-29 — bb, 2026-09-11 — T3 Code), всего 37 исследованных продуктов.
- Режим «закрыли → появился инструмент → переоткрыли» не формализован: DoD противоречит фактическому использованию трека, дедлайн «до конца Q2 2026» в Goal устарел.

### Варианты или путь решения (Solution Sketch)
- По решению владельца закрепить за эпиком evergreen-режим (вечнозелёный трек): новые продукты → новые задачи Этапа 1 + строка в сводной таблице; эпик не закрывается автоматически по исчерпанию задач.
- Внести точечные правки в `todo/EPIC-research-agent-frameworks-comparison.todo.md` (4 правки по плану), остальной текст не трогать.

### Ожидаемый результат (Expected Result)
- Эпик остаётся `in_progress` осознанно и с явной формулировкой режима в тексте эпика.
