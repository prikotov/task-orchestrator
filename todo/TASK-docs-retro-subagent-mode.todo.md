# TASK-docs-retro-subagent-mode: Запуск ретроспективы сабагентом: вход — реквизит сессии агента

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
Ретроспектива — самая контекстоёмкая работа тимлида: чтение файлов сессий, архива прошлых ретро, реестра, артефактов задач. Проведение ретро в контексте сессии-оркестратора сжигает её рабочую память, нужную для управления задачами.

### Варианты или путь решения (Solution Sketch)
Проведение ретро делегировать сабагенту с ролью тимлида (изолированный контекст). Вход — реквизит сессии агента (id или путь к файлу сессии; всё общение агента фиксируется в файле сессии целиком — дополнительная передача контекста не нужна). Ретро-агент сам читает сессию, прошлые ретро и реестр; возвращает файл ретро, запись реестра и резюме.

### Ожидаемый результат (Expected Result)
Навык `retrospective` предписывает запуск ретро сабагентом с ролью тимлида; вход — реквизит сессии; тяжёлый контекст не проходит через сессию инициатора. Полный и сессионный режимы работают одинаково в обоих исполнениях.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)
> **User Story:** Как владелец проекта, я хочу, чтобы ретроспектива выполнялась сабагентом в изолированном контексте с входом «реквизит сессии агента», чтобы контекстоёмкий анализ не сжигал рабочую память сессии-инициатора и ретро смотрело на сессию свежим взглядом.

### Цель по SMART (Goal)
Добавить в `docs/agents/skills/retrospective/SKILL.md` режим исполнения через сабагента: (1) норма — ретро проводит сабагент с ролью тимлида (запуск через `run-subagent`); (2) вход сабагента — реквизит сессии (id или путь к файлу сессии агента; у pi — `~/.pi/agent/sessions/<...>.jsonl`, у других агентов — их хранилища) и опционально артефакты (задача, эпик, PR); (3) сабагент сам читает сессию целиком — файл содержит всё общение, отдельная передача контекста не требуется; (4) выход — файл ретро, запись реестра, резюме инициатору. Изменения проходят цикл PM1–PM5.

## 2. Контекст и Границы (Context and Scope)
*   **Где делаем:** `docs/agents/skills/retrospective/SKILL.md` (раздел «Как использовать»: режим запуска); при необходимости указатели в полном и сессионном режимах
*   **Текущее поведение:** навык выполняется в контексте вызвавшей сессии; тяжёлые первоисточники читаются в её контексте
*   **Границы (Out of Scope):** изменение шагов ретро, шаблона и справочников; изменение реестра; автоматический запуск ретро; изменения в `run-subagent`

## 3. Требования, MoSCoW (Requirements)
### 🔴 Обязательно (Must Have)
- [ ] Норма исполнения: ретро проводит сабагент с ролью тимлида через `run-subagent`; обоснование — контекстоёмкость; исполнение в текущей сессии — исключение для заведомо лёгких случаев (например, ретро без чтения журналов), фиксируется явно
- [ ] Вход сабагента: реквизит сессии (id или путь к файлу сессии агента — выдаётся инфраструктурой агента, не назначается вручную) и опционально артефакты работы (задача/эпик/PR)
- [ ] Никакой отдельной передачи контекста: файл сессии содержит всё общение агента целиком — сабагент читает его сам
- [ ] Якорная сессия для полного режима (несколько сессий предмета): один реквизит — точка входа, остальные первоисточники собирает сам сабагент по Шагу 1
- [ ] Отказы входа: якорная сессия не разрешилась/не читается — ретро не проводится (отказ, не «неподтверждено»); реквизит собственной сессии неопределим — инициатор не запускает сабагента
- [ ] Резюме содержит пути созданных артефактов (файл ретро И запись в реестре) и идентификацию сессии; инициатор проверяет наличие артефактов и сверяет идентификацию с ожидаемым предметом
- [ ] Сабагент не коммитит и не пушит — публикация за инициатором по регламенту
- [ ] Завершение без резюме (таймаут/ошибка) — инициатор проверяет частичные артефакты и трассу запуска; не более одного активного ретро по предмету; повторный запуск полного режима дополняет существующий файл, а не создаёт новый
- [ ] Выход сабагента: файл ретро по шаблону, запись в реестр по штатным правилам, компактное резюме инициатору
- [ ] Оба режима (полный и сессионный) исполняются сабагентом одинаково; ключ сессии мини-режима — тот же реквизит сессии
- [ ] Цикл PM1–PM5 до этапа `DC`
### ⚫ Не будем делать (Won't Have)
- Изменение содержательных шагов ретроспективы и справочников
- Автозапуск ретро после каждой сессии
- Изменение скилла `run-subagent`
