# TASK-fix-resume-task-arg-not-in-facilitator-prompt: При resume dynamic-цепочки аргумент task не доходит до промптов фасилитатора

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
- Документация скилла brainstorm обещает: «Аргумент task обязательный, но при resume используется только как контекст для фасилитатора».
- Фактически при resume промпты `facilitator_start`/`facilitator_continue` получают ТЕМУ из `topic.md` сессии (`DynamicLoopSessionStateVo::getTopic()`); аргумент task CLI-команды в промпт фасилитатора не попадает вообще.
- Последствие: продолжить завершённую/прерванную сессию с новым материалом (например, «появились скриншоты, дайте слово участникам») невозможно — фасилитатор не видит вводную, видит только старый журнал, и решает `done:true`.
- Обход, применённый на практике (host TasK, 2026-11-21): ручная инжекция дополнения в `topic.md` и заметки в `facilitator_journal.md` сессии с бэкапами — работает, но это редактирование артефактов сессии вне контракта инструмента.

### Варианты или путь решения (Solution Sketch)
- В `DynamicExecutionStrategy::resume()` пробрасывать `$command->task` в контекст фасилитатора: либо в challenge-раунд после resume (первое сообщение фасилитатору: «Лид передал новый контекст: …»), либо в `facilitator_continue` отдельным блоком `%task_addendum%`.
- Альтернатива: явный флаг `--addendum` для resume с записью в `topic.md` сессии самим оркестратором (с версионированием/бэкапом файла), чтобы фасилитатор и все последующие шаги видели дополнение штатно.

### Ожидаемый результат (Expected Result)
- Resume с новой вводной (task) продолжает сессию по новому материалу без ручного редактирования файлов сессии: фасилитатор видит дополнение и маршрутизирует раунды по нему.

## 1. Концепция и Цель (Concept and Goal)
- Resume как штатный механизм «допить» сессию новым материалом: фасилитатор получает вводную Лида и маршрутизирует раунды по ней, без ручного редактирования файлов сессии.

- Вне скоупа: смена участников/темы на resume (уже игнорируется намеренно).
