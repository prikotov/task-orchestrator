# TASK-release-v0-5-1-preparation: Подготовить release PR для v0.5.1

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)

Исправление Composer-host уже слито в `main`, но последний опубликованный тег `v0.5.0` его не содержит. Потребители пакета не получают восстановленную загрузку профиля роли и изоляцию локального Symfony CLI cache.

### Варианты или путь решения (Solution Sketch)

Подготовить patch-релиз `v0.5.1` из `main`: кратко описать единственное исправление в CHANGELOG, оформить план релиза и создать release PR с документационными артефактами.

### Ожидаемый результат (Expected Result)

Release PR однозначно фиксирует состав `v0.5.1`, риски и последующие шаги публикации, поэтому после его слияния можно безопасно создать тег из `main`.

## 1. Концепция и Цель (Concept and Goal)

### История (Job Story)

> **Job Story:** Когда исправление Composer-host слито в `main`, я хочу подготовить release PR для patch-релиза, чтобы потребители получили исправление в следующем опубликованном теге.

### Цель по SMART (Goal)

Подготовить и проверить документационные артефакты запроса подготовки релиза (release PR) для `v0.5.1`, создать запрос в `main`, перевести задачу в `review`, а после зелёной непрерывной интеграции — в `done` до запроса одобрения. Публикация тега остаётся отдельным операционным этапом после слияния.
