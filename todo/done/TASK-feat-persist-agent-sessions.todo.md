# TASK-feat-persist-agent-sessions: Сохранять нативные сессии агентов для метрик

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
Запуски Pi и Codex отключают или подавляют сохранение нативных сессий. Из-за этого dashboard не может собрать полную статистику токенов и эффективности после завершения запуска.

### Варианты или путь решения (Solution Sketch)
Убрать флаги, отключающие сохранение сессий, из стандартных команд Pi, Codex и профилей ролей. Зафиксировать это поведение тестами и документацией.

### Ожидаемый результат (Expected Result)
Новые запуски агентов создают нативные журналы сессий в стандартных каталогах CLI, а существующий сборщик dashboard может использовать их для статистики без дополнительного режима управления.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)
> Как владелец оркестратора, я хочу сохранять нативные сессии Pi и Codex, чтобы видеть фактическое использование токенов после завершения запусков.

### Цель по SMART (Goal)
Включить сохранение нативных сессий во всех активных командах запуска Pi и Codex, проверить отсутствие отключающих флагов в конфигурации и покрыть стандартные команды тестами до создания PR.

## 2. Контекст и Границы (Context and Scope)
* **Где делаем:** `config/chains.yaml`, Pi runner, `watch-subagent.sh`, связанные тесты и документация.
* **Текущее поведение:** Pi запускается с `--no-session`, а часть Codex-профилей — с `--ephemeral`; нативные журналы не всегда доступны сборщику статистики.
* **Границы (Out of Scope):** изменение collector dashboard, переработка формата JSONL, добавление управляемого режима persistence и восстановление исторических запусков.

## 7. Риски и зависимости (Risks and Dependencies)
- Нативные сессии содержат локальные промпты и ответы; они остаются на машине запуска и не отправляются collector-ом во внешние сервисы.
- Исторические запуски, выполненные без persistence, восстановить нельзя.
- Codex сохраняет rollout по умолчанию; существующий явный `WATCH_CODEX_EPHEMERAL=1` остаётся обратным opt-out для ручного запуска.
