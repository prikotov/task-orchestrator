# TASK-feat-dag-orchestration: Оркестрация на основе направленного ациклического графа (DAG)

## 1. Concept and Goal (Концепция и Цель)
### Story (Job Story)
Когда цепочка содержит шаги с произвольными зависимостями (A → B, A → C, B+C → D), я хочу объявлять зависимости явно, чтобы оркестратор строил оптимальный порядок выполнения и запускал независимые шаги параллельно.

### Goal (Цель по SMART)
Реализовать DAG-based execution engine: шаги объявляют `depends_on`, оркестратор строит топологический порядок, независимые шаги выполняются параллельно.

## 2. Context and Scope (Контекст и Границы)
* **Текущее состояние:** Линейное выполнение (static/conditional) или цикл (dynamic). Нет поддержки произвольных графов зависимостей.
* **Обобщение:** Parallel execution (TASK-feat-parallel-execution) = частный случай DAG с плоскими группами. DAG = общий случай.
* **Границы (Out of Scope):**
  - Циклы в графе (DAG = ациклический по определению)
  - Динамическое изменение графа во время выполнения

## 3. Requirements (Требования, MoSCoW)
### 🔴 Must Have (Обязательно)
- [ ] YAML DSL: `depends_on` на уровне шага (список имён шагов)
- [ ] Валидация графа: обнаружение циклов, несуществующих зависимостей
- [ ] Топологическая сортировка и параллельный запуск независимых шагов
- [ ] Обратная совместимость: цепочки без `depends_on` работают как раньше

### 🟡 Should Have (Желательно)
- [ ] Визуализация графа (Mermaid/dot)
- [ ] Условные рёбра (выполнять зависимость только при условии)
