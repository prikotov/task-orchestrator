# TASK-feat-parallel-execution: Параллельное выполнение шагов цепочки

## 1. Concept and Goal (Концепция и Цель)
### Story (Job Story)
Когда цепочка содержит независимые шаги (например, статический анализ + тесты + Psalm), я хочу запускать их параллельно, чтобы сократить общее время выполнения цепочки.

### Goal (Цель по SMART)
Добавить в YAML DSL возможность указывать параллельные группы шагов. Оркестратор запускает шаги одной группы конкурентно, ждёт завершения всех, затем переходит к следующей группе.

## 2. Context and Scope (Контекст и Границы)
* **Текущее состояние:** Все шаги выполняются последовательно. 3 независимых шага по 60с = 180с вместо 60с.
* **Границы (Out of Scope):**
  - DAG с произвольными зависимостями (см. TASK-feat-dag-orchestration)
  - Параллельный запуск сабагентов (разные цепочки)

## 3. Requirements (Требования, MoSCoW)
### 🔴 Must Have (Обязательно)
- [ ] YAML DSL: `parallel_group` на уровне шага
- [ ] Оркестратор запускает шаги одной группы конкурентно (Fiber / Process)
- [ ] Ошибка одного шага в группе → группа помечается failed, остальные отменяются
- [ ] Обратная совместимость: цепочки без `parallel_group` работают как раньше

### 🟡 Should Have (Желательно)
- [ ] `depends_on` для явного указания зависимостей между шагами
