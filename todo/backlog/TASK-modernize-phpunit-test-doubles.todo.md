# TASK-modernize-phpunit-test-doubles: Устранить уведомления тестовых двойников PHPUnit

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
- После обновления до PHPUnit 13 тесты проходят, но 277 раз сообщают о mock-объектах без ожиданий и 45 тестов используют устаревающую комбинацию `with*()` без `expects()`.
- PHPUnit 14 удалит поддержку второго случая, а многочисленные уведомления скрывают новые проблемы.

### Варианты или путь решения (Solution Sketch)
- Заменить объекты без проверяемых взаимодействий на stubs.
- Для действительно проверяемых взаимодействий добавить явные ожидания.

### Ожидаемый результат (Expected Result)
- PHPUnit выполняет набор тестов без собственных уведомлений и устаревших вызовов.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)
> Как разработчик, я хочу видеть чистый вывод тестов, чтобы новые предупреждения не терялись и переход на PHPUnit 14 не блокировался.

### Цель по SMART (Goal)
- Устранить 277 PHPUnit notices и 45 затронутых устареванием тестов без изменения проверяемого поведения.

## 2. Контекст и Границы (Context and Scope)
- **Где делаем:** 34 класса модульных и интеграционных тестов, перечисляемых PHPUnit 13.
- **Вне границ:** изменение production-кода и обновление до PHPUnit 14.

## 3. Требования, MoSCoW (Requirements)
### 🔴 Обязательно (Must Have)
- [ ] Заменить mock-объекты без ожиданий на stubs.
- [ ] Добавить ожидания там, где тест проверяет взаимодействие.
- [ ] Запустить PHPUnit с отображением всех собственных уведомлений.
- [ ] Выполнить `make check`.
### ⚫ Won't Have (Не будем делать)
- Подавление уведомлений атрибутом `AllowMockObjectsWithoutExpectations` вместо исправления тестовых двойников.

## 4. План реализации (Implementation Plan)
1. [ ] Сгруппировать уведомления по тестовым классам и зависимостям.
2. [ ] Разделить stubs и mocks по назначению.
3. [ ] Устранить вызовы `with*()` без ожиданий.
4. [ ] Выполнить полный набор проверок.

## 5. Критерии приёмки (Definition of Done)
- [ ] PHPUnit сообщает 0 PHPUnit notices и 0 PHPUnit deprecations.
- [ ] Количество и смысл тестов не уменьшены.

## 6. Самопроверка (Verification)
```bash
vendor/bin/phpunit --display-phpunit-deprecations --display-phpunit-notices
make check
```

## 7. Риски и зависимости (Risks and Dependencies)
- Механическая замена может ослабить проверку взаимодействий; каждый тест нужно классифицировать по назначению двойника.
- Зависит от завершения `TASK-update-all-dependencies`.

## 8. Источники (Sources)
- Диагностика PHPUnit 13.3.3 после полного обновления зависимостей.
