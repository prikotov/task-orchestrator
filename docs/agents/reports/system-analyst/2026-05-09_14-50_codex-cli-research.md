## Краткое резюме

Исследован Codex CLI (OpenAI) по 10 критериям для оценки пригодности как сабагента в нашей системе ролей и скиллов.

**Вердикт: ⚠️ Частично подходит (6/10)**

### Ключевые находки

- 🔴 **Нет `--append-system-prompt`** — невозможно дополнить системный промпт, только полная замена через файл. Роль инжектируется через user prompt.
- 🔴 **Нет `--skill` CLI** — все скиллы глобальны (`~/.codex/skills/`), нельзя назначить разные скиллы разным ролям.
- 🔴 **Нет автосканирования `.agents/skills/`** — проектные скиллы не обнаруживаются.
- 🟡 **Бедная JSONL-телеметрия** — нет детальных событий по tool execution и per-turn токенам.
- 🟡 **Провайдеры ограничены** — OpenAI + OSS (Ollama, LM Studio) + BYOK, нет 20+ провайдеров.
- ✅ **AGENTS.md автообнаружение** — работает из коробки.
- ✅ **Ephemeral-режим** — изолированный запуск через `--ephemeral`.
- ✅ **Профили** — пресеты конфигурации через `-p/--profile`.
- ✅ **Output schema** — валидация ответа по JSON Schema.
- ✅ **Apache-2.0 лицензия** — open source, пермиссивная.

### Рекомендация

- **Pi — основной сабагент** (10/10), лучше адаптирован к программному запуску.
- **Codex — интерактивный агент**, для TUI-работы с approval и sandbox.
- **Codex как backup-сабагент** возможен через wrapper, но потребует компенсации отсутствующих фич.
