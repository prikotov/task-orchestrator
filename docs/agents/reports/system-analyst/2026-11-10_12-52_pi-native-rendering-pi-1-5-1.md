**Задача:** Проверка соответствия скилла новым возможностям mermaid-рендеринга pi 1.5.1 и правилам кликабельных ссылок; правка скилла по итогам.

## Контекст

Вышел pi 1.5.1 с заметкой «Richer Mermaid diagrams»: pie-диаграммы, авторские стили, кликабельные подписи на поддерживаемых терминалах, диаграммы в развёрнутых branch- и compaction-summaries. Скилл `pi-native-rendering` содержал устаревшие ограничения.

## Находки

### 1. Ограничение типов диаграмм в скилле устарело

Скилл запрещал `pie/gitGraph/mindmap` («в терминале НЕ рисуются»). Фактические возможности рендерера `lovely-mermaid@0.3.3` (по `README.md` и `dist/index.d.ts` пакета):

| Тип | Статус в pi 1.5.1 |
|---|---|
| `flowchart`/`graph` (subgraph, v2-формы `A@{shape:…}`) | рисуется (и раньше) |
| `sequenceDiagram` (активации, notes, `loop`/`alt`/`opt`, `autonumber`) | рисуется (и раньше) |
| `stateDiagram(-v2)`, `classDiagram`, `erDiagram` | рисуются (и раньше) |
| `pie` — bar-list, `showData` добавляет значения | **новое**, был запрещён в скилле |
| `mindmap` — дерево `├──`/`└──` | **новое**, был запрещён в скилле |
| `timeline` — вертикальный список | **новое**, в скилле не упоминался |
| `gitGraph` — lane-стиль `git log --graph` | **новое**, был запрещён в скилле |
| `gantt`, `journey`, `quadrantChart`, `sankey`, `block-beta`, `radar`, C4 | по-прежнему НЕ рисуются |

Авторские стили: `classDef`, `A:::hot`, `class`, `style` (`fill`/`stroke`/`color`/`font-weight:bold`) применяются best-effort во всех грамматиках. Клик-ссылки в диаграммах (`click A "url"`, `link A "url"`) эмитятся как OSC 8. Диаграммы в развёрнутых branch-/compaction-summaries pi рисует сам — действий агента не требуется.

### 2. Правил кликабельности путей/ссылок в скиллах не было

Механика (по коду `pi-tui` и встроенного markdown-парсера pi):

- Кликабельность даёт только markdown-ссылка: рендерер превращает `[текст](href)` в OSC 8. Голые пути файлов в тексте не линкуются (автолинк — только `http(s)`/`ftp`/`www`/email).
- `href` каждого распарсенного звена проходит через `encodeURI()` — пробелы и кириллица кодируются в `%20`/UTF-8-percent автоматически, но только если ссылка распарсилась.
- Markdown-ссылка без угловых скобок ломается на первом пробеле: destination останавливается на пробеле (`[файл](/tmp/pi link demo/x.txt)` → href `/tmp/pi`).
- Форматы ссылок — эмпирическая матрица клик-теста в ghostty (2026-11-10, шесть вариантов на один файл): относительный и `./относительный` — отказ «Не удалось распознать схему URI» (плюс независимый случай `out/01-smoke.mp3` в другом окне); `~/путь` — отказ; `/абсолютный/путь` без схемы — открывается (спец-обработка POSIX-путей в ghostty, вне стандарта OSC 8); `file:///абсолютный` и `https://` — работают. Опции резолва относительных URI у ghostty нет (`link-osc8` — только вкл/выкл). Вывод: эталон для ответов — `file://`/`https://` (переносимо между терминалами), безсхемные пути не использовать.
- Знаки препинания: в href попадает ровно то, что стоит в `(…)` явной markdown-ссылки. Точка предложения внутри скобок приклеивается к URI и ломает путь даже при корректной схеме; в подписи — грязнит подчёркивание. Голые autolink-URL парсер защищает (отсекает хвостовую пунктуацию), явные ссылки — нет. В случае `out/01-smoke.mp3` точка оказалась в подписи (URI в диалоге ошибки — без точки), отказ — из-за отсутствия схемы.
- Ссылки в код-блоках не кликабельны; raw OSC 8-последовательности в тексте ответа — не применять.
- Терминальная сторона: внутри tmux/screen pi отключает OSC 8 (детект через окружение), переопределение — `terminal.hyperlinks` / `PI_HYPERLINKS`. У пользователя ghostty без tmux — OSC 8 активен.

## Что изменено

`docs/agents/skills/pi-native-rendering/SKILL.md`:

1. Актуализирован список рисуемых типов (добавлены `pie`, `mindmap`, `timeline`, `gitGraph`); запрет перенесён на реально нерисуемые типы (`gantt`/`journey`/`quadrantChart`/`sankey`); добавлена строка про best-effort стили автора.
2. Добавлен блок «Кликабельность»: абсолютный URI со схемой, `file://` в угловых скобках, последствия для голых/относительных путей и код-блоков, правило пунктуации за закрывающей скобкой.
3. `description` дополнен упоминанием кликабельных ссылок (OSC 8) — для попадания задач «путь/ссылка в чате» в триггеры скилла.

Роли правок не требуют: 7 ролей подключают скилл по ссылке и собственных ограничений по типам диаграмм не содержат. `docs/guide/diagrams.md` не затронут — это mermaid-исходники для рендеринга на GitHub.
