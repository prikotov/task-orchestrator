## 3. Edge cases (проверены статически)

- **Растянутый первый тик** (soft раньше второго heartbeat): даёт 1 heartbeat → ассерт ≥2 валит тест громко. Ложного прохода нет.
- **Поломка парсинга `ps times`** (`time=` вместо `times=`, не-число, пустой вывод): `cpu_now=0` на всех замерах → `live=idle` на тике 2 → дискриминатор срабатывает. Подтверждено мутацией.
- **Регрессия сравнения дельты** (`>` → `>=`): CPU-тест проходит, но idle-тест `stallKillsIdleProcessEvenWithLivenessGate` падает (спящий процесс с нулевыми дельтами стал бы active, stall подавлен). Перекрёстное покрытие есть.
- **Осиротевший busy-loop** при сбое watcher'а: ограничен 60с в самом режиме `FAKE_RUNNER_HANG_CPU` (строка 1064), `processTimeout=30` в PHPUnit — двойная страховка.
- **`substr_count('watcher_heartbeat')`**: RUN SUMMARY и прочие записи строку не содержат — счётчик честный.
