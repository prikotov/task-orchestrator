## 2. Корректность фактических утверждений

Формула сверена с первоисточником `docs/agents/skills/run-subagent/scripts/watch-subagent.sh`, фактический блок — строки **1098–1106**:

```bash
EFFECTIVE_HARD=${HARD_TIMEOUT}          # HARD_TIMEOUT=1800 (строка 90)
if [[ -n "$SOFT_TIMEOUT" ]]; then
    computed_hard=$((SOFT_TIMEOUT * 2))
    if [[ $computed_hard -gt $EFFECTIVE_HARD ]]; then
        EFFECTIVE_HARD=$computed_hard
    fi
fi
```

- При незаданном `-m`: `effective_hard = max(soft × 2, 1800)` — утверждение скилла верно, оговорка «при незаданном `-m`» присутствует (важно: при явном `-m` формула `max(soft × 2, m)`).
- «Поднимать `-m` при перезапуске вручную не нужно» — верно: ceiling растёт автоматически (900→1350 даёт hard 1800→2700).
- Ячейка «По умолчанию: max(soft × 2, 1800)» в `run-subagent/SKILL.md` описывает эффективный дефолт корректно (`-s` обязателен, формула всегда определена).
- Базовая таблица C0–C5 не изменена (Won't Have соблюдён), добавлен только заголовок «Базовый soft-timeout — по сложности задачи».
