## 5. Выполненные проверки (верификация ревьювера)

1. **YAML:** `yaml.safe_load` — файл парсится; jobs: `test`, `phar-smoke`, `composer-host-smoke`, `doc-checks`; триггеры не изменены.
2. **Heredoc заглушки:** после YAML-разбора содержимое и терминатор `EOF` находятся в колонке 0 (`<<'EOF'`, не `<<-`) — корректно; итоговый файл заглушки проверен побайтно.
3. **Симуляция чистого checkout** (временный каталог вне `/tmp` — сканер скипает `tmp/`; только tracked-файлы + симлинк `vendor`):
   * шаг `Materialize ignored doc paths` — rc=0; симлинки разрешаются (`docs/../vendor/...`), vendor-пути существуют;
   * `validate-md-links` — **405 файлов, все ссылки зелёные** (404 tracked в scope с учётом exclude из `.md-links.php` + 1 заглушка);
   * **без materialize-шага — 90 битых ссылок в 22 файлах** → шаг необходим, не декоративный;
   * **негативная проверка инструмента:** добавлена битая ссылка `guide/definitely-missing-file.md` → `✗ Found 1 broken link(s)`, rc=1.
4. **Симлинки и сканер:** `RecursiveDirectoryIterator` без `FOLLOW_SYMLINKS` — в симлинк-каталоги не спускается; 132 vendor-md не попали в скан (405 = 404 + заглушка). Комментарий в job правдив. `validate-language` дополнительно исключает `docs/conventions|todo-md|git-workflow` в `.coding-standard.php`.
5. **Якоря заглушки:** единственные два используемых якоря `todo/AGENTS.md#декомпозиция-задач` и `#процесс-работы-с-задачами` (поиск по tracked-докам) покрываются заголовками заглушки; сканер проверяет якоря — симуляция зелёная.
6. **Regex фильтра:** прогнан на 14 образцах путей — docs/todo/README*/AGENTS.md/Makefile/.md-links.php/.coding-standard.php/composer.{json,lock}/.github/workflows → RUN; `src/`, `apps/`, `tests/` → SKIP. `composer.lock` в фильтре корректно ловит смену версий vendor-доков. Пустой дифф → `run=false` (grep без совпадений). Трёхточечный дифф `BASE_SHA...HEAD` с `fetch-depth: 0` на merge-ref — корректный стандартный паттерн.
7. **Безопасность job:** секретов нет; выражения `${{ }}` переданы через `env` (нет инъекции скрипта из event payload); `pull_request` (не `pull_request_target`); сеть — только checkout/setup-php/composer (необходимый минимум); `md-links` проверяет только внутренние ссылки (внешние пропускаются инструментом) — детерминированность подтверждена; `set -euo pipefail` во всех run-блоках. Уязвимостей не обнаружено.
8. **Локальный эквивалент:** `make md-links validate-todo validate-language` — rc=0 (validate-language: 20 файлов с превышением доли англицизмов, warning mode, exit 0 — существующий baseline, не регрессия этого диффа).
9. **PHPUnit/Psalm:** пропущены обоснованно — дифф строго ограничен CI-YAML и Markdown-документацией, PHP-код, конфигурации приложения и скрипты не затронуты (исключение AGENTS.md «Предварительные проверки»); вместо них выполнены затронутые doc-проверки (п. 8).

## 6. Риски и допущения

* Допущение: ревью по рабочему дереву эквивалентно будущему коммиту ветки; после коммита состав диффа должен совпасть с проверенным (3 файла + задача).
* Риск: фактическое время job в CI не измерено (локально `composer install` не эмулировался — vendor подсунут симлинком); заявленные «секунды» требуют подтверждения реальным прогоном (CR-2).
* Риск: `github.event.pull_request.base.sha` при сильно устаревшем merge-ref может дать дифф шире фактического — эффект лишь в лишнем запуске проверок, не в пропуске; приемлемо.
* Симуляция не воспроизводит сетевое окружение GitHub Actions; негативный прогон на черновой ветке (требование задачи) остаётся обязательным.
