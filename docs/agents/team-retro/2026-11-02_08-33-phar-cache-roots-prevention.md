## Оценка ролей

- **Тимлид Алекс** (`docs/agents/roles/team/team_lead_alex.ru.md`)
  - **Плюсы:** контрольная точка после каждого этапа (`git status` + адресный grep артефактов) поймала три отклонения до того, как они стали дороже: пустой запуск Гермионы (5 с, exit 0, без правок), цикл bash-проверок без правок, неверное строковое замечание ревьюера (отвергнуто по сверке с кодом). Конвейер RACI 5.7 соблюдён, merge выполнен только после явного подтверждения пользователя.
  - **Минусы:** первый push PR-ветки выполнен по рецепту, транскрибированному по памяти, а не скопированному дословно из `docs/guide/agent-identity.md` — упал с `missing config value GIT_CONFIG_VALUE_4` (exit 128); `assignee` при старте задачи дважды выставлялся неверно («Аналитик (Шерлок)» → warning валидатора → «Аналитик Шерлок (pi)»).
  - **Предложения по улучшению:** рецепты из документации копировать дословно (см. проблемы 4–5); строковые замечания ревьюера сверять с кодом до делегирования правок.
- **Аналитик Шерлок** (`docs/agents/roles/team/system_analyst_sherlock.ru.md`)
  - **Плюсы:** 22 факта с трассировкой `файл:строка` + эмпирика записи в `phar://` (два прогона PHP CLI); после перезапуска сужение объёма по подсказке сработало — этап сдан в бюджет.
  - **Минусы:** первый запуск убит по soft-timeout 600 с без единого артефакта (файл отчёта не создан) — секция «Факты» писалась в конец, а не инкрементально.
  - **Предложения по улучшению:** для документных этапов писать результат в файл инкрементально (шалон → наполнение), чтобы частичный прогресс переживал таймаут.
- **Архитектор Локи** (`docs/agents/roles/team/system_architect_loki.ru.md`)
  - **Плюсы:** сверх фактов проверил 5 слепых зон своими руками (D1–D5), включая потребителей замороженных параметров; поймал некорректность постановки П2 в standalone и асимметрию freshness-проверки контейнера. Уложился в один запуск (900 с).
  - **Минусы:** Без замечаний.
  - **Предложения по улучшению:** Без предложений.
- **Технический писатель Гермиона** (`docs/agents/roles/team/technical_writer_hermione.ru.md`)
  - **Плюсы:** успешный прогон DC собрал два черновика в цельный отчёт с резюме; финальный запуск по точным парам oldText/newText внёс 3 правки без циклов.
  - **Минусы:** 2 из 4 запусков неэффективны: (1) 5 с, exit 0, ответ — текстовый дубль tool_call без вызова инструмента; (2) 601 с, 554 вызова bash-проверок, файл не изменён (см. проблему 2).
  - **Предложения по улучшению:** при работе от лица роли в конвейере — правки вносить до контрольных чтений; повторные чтения файла не переключают поведение.
- **Ревьювер Бэка Пуаро** (`docs/agents/roles/team/code_reviewer_backend_puaro.ru.md`)
  - **Плюсы:** сверил 20+ ссылок по коду, целостную карту замечаний дал с первого прохода; явно разделил блокирующее/неблокирующее.
  - **Минусы:** одно из трёх строковых замечаний неверно (утверждал, что class-level комментарий `src/Kernel.php:62-64` фактически занимает 61–63 — сверка показала, что 62–64 верно; второе замечание было частично верным: `56-61` → `56-60`).
  - **Предложения по улучшению:** диапазоны `файл:строка` сверять по коду до включения в отчёт (см. предложение 2).

## Проблемы

- **⚠️ Повтор из ретро `2026-08-18_19-21-retro-registry-standard.md`:** формат `assignee` для командных ролей не документирован — при старте задачи выставлено «Аналитик (Шерлок)», валидатор выдал warning, верный формат («Аналитик Шерлок (pi)») найден чтением `.todo-md.php`. *(доказательство: сессия инициатора, `php vendor/bin/todo-md set ... assignee=...` → warning "`assignee` must use format `<роль> (<агент>)`"; направление: Инструкции)*
- **Сабагент-редактор циклится в контрольных вызовах и не вносит правки:** прогон Гермионы 2026-10-30 11:25:53 → 11:35:54 (601 с, soft_timeout) — 554 вызова `bash` (grep/sed по документу и коду), ноль изменений файла; отдельный запуск 11:25:03 завершился за 5 с с exit 0 и текстовым дублем tool_call без вызова инструмента. Оба пойманы контролем артефактов. *(доказательство: `var/log/watch-subagent/20261030_112553-pi-technical-writer-hermione-2770920/events/events.ndjson`, `.../20261030_112503-...-2769887/run.log`; `git status` без изменений после обоих; направление: Инструменты/Координация)*
- **Неверные диапазоны `файл:строка` в замечаниях ревьюера:** Пуаро в RV-отчёте §6 предложил «исправить» `src/Kernel.php:62-64` на 61–63 — сверка `sed -n '55,65p' src/Kernel.php` показала, что документ верен; второе замечание частично верно (`56-61` → фактически `56-60`). Если бы правки делегировались без сверки, в отчёт попала бы ошибочная ссылка. *(доказательство: RV-вывод сабагента в сессии; `src/Kernel.php:56-64`; направление: Координация)*
- **Soft-timeout 600 с (C2) мал для документных этапов:** первый запуск Шерлока (AN) убит на 600 с без артефактов (`run.log` 20261030_103251, reason=soft), перезапуск на 900 с — успех; первый запуск Гермионы (DC) убит на 600 с без правок (`run.log` 20261030_110726), перезапуск на 900 с — успех. Причина класса та же, что в реестровой записи про `make check` и таймауты, но ось другая — документная работа без `make check`. *(доказательство: два `run.log` с reason=soft_timeout; направление: Процессы)*
- **Транскрипция многошагового рецепта по памяти:** первый push ветки выполнен по воспроизведённому по памяти рецепту из `docs/guide/agent-identity.md` — перепутаны `GIT_CONFIG_KEY_4`/`GIT_CONFIG_VALUE_4`, push упал (exit 128); повторный запуск дословно по документу — успех. *(доказательство: сессия инициатора, вывод первой попытки `error: missing config value GIT_CONFIG_VALUE_4`; направление: Инструкции)*
