# Ретроспектива: TASK-fix-watch-subagent-sigpipe-exit-141 — ложный код 141 watcher-а

**Дата:** 2026-09-13
**Задача:** `TASK-fix-watch-subagent-sigpipe-exit-141` (1 задача, 1 PR — #390)
**Что делали:** устранили ложный внешний код `141` (SIGPIPE — сигнал «запись в закрытый канал») после успешного завершения сабагента: два early-closing конвейера (конвейера с ранним закрытием потребителя) в `emit_run_summary()` заменены на однопроходные awk, добавлены два регрессионных теста (50 000 событий и 10 000 уникальных типов). Конвейер: реализация → самопроверка → доработка ×2 → ревью → PR.

## Проблемы

- Soft-таймаут 600с (C2) не вмещает реализацию плюс `make check`: первый запуск убит при готовой реализации на проверках. ⚠️ Повтор записи «Таблица таймаутов `task-via-subagents` не учитывает `make check` в промпте» ([2026-08-20](2026-08-20_00-36-techdebt-phpmd-lengths.md)) — счётчик стал 2.
- `cost_fact: 90000` записан прикидкой «на глаз» без измерения; по COST.md источник факта — billing/usage-журнал. Фактический расход — 3 026 280 токенов по шести сессиям сабагентов: расхождение ~34 раз. Поле исправлено в PR #390 (оценка перенесена в `cost_plan`); в реестре ~180 задач стоимость заполнена у шести, и старые «факты» — такие же круглые прикидки.
- Тестовые прогоны сабагента писали в дефолтный каталог `var/log/watch-subagent` и стёрли run-каталог активного watcher-а Тимлида: инцидент 141 остался без собственного `run.log`, причину восстанавливали косвенно.
- Расхождение формата `pr`: SKILL `task-via-subagents` предписывает `pr: '#<NUMBER>'`, а CLI `todo-md done` требует полный URL — перевод в `done` падает до ручной правки поля.
