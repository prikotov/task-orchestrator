# Ретроспектива: bot-account — GitHub App `prikotov-agent` identity для AI-агентов

**Дата:** 2026-06-20
**Задача:** `TASK-chore-bot-account-for-agent` (1 задача, 1 PR #275, 5 коммитов)
**Сложность:** C2
**Что делали:** Разделение идентичности AI-агента и владельца репо. Раньше `gh` работал от `prikotov` → агент не мог approve свой PR → branch protection обходилась через `--admin`. Решение: GitHub App `prikotov-agent` (одна идентичность на все ~36 репо и всех агентов pi/codex/opencode, короткоживущие installation tokens). Реализован PHP-скрипт `bin/agent-token` (JWT RS256 через `ext-openssl`, без зависимостей, кеш) + гайд `docs/guide/agent-identity.md`.

**Роли:** Тимлид Алекс, Бэкендер Тони (реализация), Тех. писатель Гермиона (документация), Ревьювер Бэка Пуаро (code review).

## Проблемы

- ⚠️ **Повтор «неполные метаданные задач после сабагента»** (ретро 2026-04-22, 2026-04-27, 2026-06-15 — **4-я ретро подряд**). В новом виде: `git mv todo/... → done/...` не перенёс unstaged-правки метаданных (status=done, pr=#275, чек-листы, history), которые я внёс ПОСЛЕ переноса. Потребовался отдельный коммит-поправка. Предложение «добавить чеклист перед commit в SKILL» звучало в трёх прошлых ретро — **не внедрено**, повторилось снова.

- 🟡 **2 сабагента упали (stall + soft-timeout).** Тони (доработка по CR) завис по `stall` (`runner_failed_after_agent_end`, exit 143); Тони (последняя итерация N-1..N-4) ушёл по `soft-timeout` 800с. В обоих случаях код был внесён ДО падения — я это проверял и продолжал. Частичный повтор «таймауты сабагентов» (ретро 2026-04-22), но митигирован правильно.

- 🟡 **Конвенция «генерируемые vs отслеживаемые каталоги docs/» нигде явно не зафиксирована.** Гермиона не знала, что `docs/git-workflow/`, `docs/conventions/`, `docs/todo-md/` генерируются init-скриптом и в `docs/.gitignore` — попыталась положить гайд туда первой итерацией. - 🟢 **Pre-commit gitleaks заблокировал тестовые PEM-фикстуры.** Стандартная ситуация для throwaway RSA-ключей в тестах, но потребовала отдельной итерации (вынос synthetic-фрагмента в `fixtures/` + расширение `allowlist`). Предсказуемо, можно было заложить в изначальный промпт Тони.

- 🟢 **Постановка в backlog изначально уводила не туда.** Исходная формулировка («бот на агента», варианты A/B) базировалась на неверной модели. Потребовался рефрейминг. Корень: задачи в backlog не проходят валидацию модели перед переносом в `todo/`.
