## Что прошло хорошо

- **Инструмент brainstorm протестирован и работает.** 4 раунда (Тони, Локи, Левша, Гэндальф) дали качественное архитектурное обсуждение с ссылками на реальный код (`RetryingAgentRunnerService`, `ErrorClassificationVo`) и ловлей на логических дырах. Участники сошлись на явном поле `fallback` в `chains.yaml` и заспорили о месте fallback-логики (`AgentRunner` vs `ChainExecution`).
- **Ироничное самотестирование:** тема brainstorm (fallback раннера при сбое) воспроизвелась вживую — сессия упала именно из-за того класса ошибок, что обсуждался. Тезис Гэндальфа/Левши «нужен структурный контракт ошибки» доказан на практике и немедленно реализован в PR #286.
- **Root cause установлен и по-настоящему закрыт.** `pi` выходит `exit 0`, сообщая об ошибке внутри JSONL (`stopReason:"error"` + `errorMessage`); парсер это игнорировал → маскировалось под `Agent returned empty output.` Теперь `PiAgentRunnerService` возвращает реальный `errorMessage`. Закрыт Action Item «Investigate empty Sherlock responses» (ретро 2026-06-30, висел с пометкой «первопричина не установлена»).
- **Тимлид НЕ писал код** в этот раз — соблюл железное правило (регресс после ретро 2026-06-30 не повторился).
- **CI зелёный** с первого пуша: `test` (1m6s) + `phar-smoke` (15s), merge clean, approve от человека-владельца.

## Проблемы

- 🔴 **Серия нарушений дисциплины Тимлида (4 пункта, см. «Оценка ролей»).** Корень один: **удобный нарратив вместо фактов и действия.** Тимлид спешил к «решению» (переключить на zai, свалить в одну задачу, заявить «фиксирую»), минуя дисциплину (прочитать audit, декомпозировать, реально записать). Это системный паттерн, не разовые огрехи.
- 🔴 **Повтор Action Item'а, описанного в прошлой ретро, но не внедрённого.** Ретро 2026-06-30 задокументировала: «`watch-subagent.sh` не грузит `.env.local` → codex падает с 403; рабочий путь — `agent:run`». Сегодня Тимлид снова потерял запуск review на этот 403, прежде чем вспомнил про задокументированный workaround. **Action Items ретро не трекаются → повторяются** (тот же симптом, что в ретро 2026-06-30 «Action Items не трекаются — ПОВТОР»).
- 🔴 **Инфраструктурная нестабильность раннеров мешает конвейеру.** Делегирование Левше упёрлось в 3 stall подряд (`zai`/`glm-5.1` не стримит события при tool-use → `watch-subagent` убивает по stall, хотя работа выполняется). Review через codex — в 403 Cloudflare (через `watch-subagent`). Конвейер `task-via-subagents` (self-review + code review через `watch-subagent.sh`) **фактически неработоспособен** на текущих раннерах без ручного обхода через `agent:run`.
- 🟡 **«Empty output» как диагноз — антипаттерн телеметрии.** При `exit 0` сырой stdout/stderr `pi` отбрасывается (`PiAgentRunnerService::run()`), поэтому в артефактах сессии не осталось следа `No API key` — пришлось воспроизведение руками. Это отдельная дыра → `TASK-fix-pi-runner-raw-output-telemetry` (TODO).
- 🟡 **Конфигурационный долг: профиль Шерлока на `pi`+`openai-codex` без ключа.** Корень инцидента (не единственный — баг парсера тоже), но без ключа `openai-codex` Шерлок в принципе неработоспособен через `pi`. → `TASK-fix-sherlock-runner-provider-config` (TODO).
