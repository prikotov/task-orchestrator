- Стандарт продемонстрирован немедленно: эта ретро обновляет реестр в той же ветке PR (правило «ретро в ветке PR до слияния» из ретро 2026-08-18_10-35 выполняется).
- Эскалация по итогам пилота сработала как задумано: «Сначала данные, потом гипотезы» (3 упоминания) → задача `TASK-docs-teamlead-data-before-hypotheses`; «Action items ретро не трекаются» → resolved самим механизмом без лишней задачи (правило «закрыта текущей задачей/PR → сразу resolved» отработало на первом же применении).

## Проблемы

- 🟡 **Молчание/зависание модели zai (glm) при делегировании через pi** — два запуска подряд зависли на генерации (stall 360с и 600с, процесс idle по CPU/IO — подлинное зависание провайдера, не раннее убийство вотчером; запись реестра про ранние таймауты из PR #352 — другой случай). Потеряно ~18 минут, артефактов нет. Повторы: 2026-06-30, 2026-08-18_10-35, эта ретро — порог 3 достигнут.
- 🟡 **gitignored `todo/AGENTS.md` делает Should-требование задачи невыполнимым в PR** — ссылка на реестр и исключение для ретро-задач внесены исполнителем в локальный файл, но в репозиторий они не попадают: для команды механика невидима. Повтор класса «неочевидные gitignored-файлы» (2026-04-20 `config/chains.yaml`, 2026-06-20 каталоги `docs/`) — порог 3 достигнут.
- 🟢 **Смена раннера сабагента без подтверждения владельца** — серая зона: конвейер велит эскалировать, `run-subagent` позволяет override, прецедент был, правила нет.
- 🟢 **Формат `assignee` для командных ролей не документирован** — валидатор требует `<роль> (<агент>)`, а в `docs/todo-md/reference/AI_AGENTS.md` перечислены только CLI-агенты; исполнитель исправил наугад (`Гермиона (codex)`).
