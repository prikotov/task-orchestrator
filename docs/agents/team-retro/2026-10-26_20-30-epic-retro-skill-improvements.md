## Что прошло хорошо

- Конвейер «модель PM1–PM5 → консультации → оформление → сверка → self-review → ревью → доработка → мерж» → обе документационные задачи прошли с первого прохода ревью после доработки, без эскалаций → повторять для задач изменения навыков и регламентов.
- «Сначала данные, потом гипотезы» при диагностике сбоя Пуаро (curl-эксперименты → NO_PROXY-гипотеза → фикс с тестом) → причина локализована за один цикл, закрыта задачей [TASK-fix-run-subagent-local-proxy](../../../todo/done/TASK-fix-run-subagent-local-proxy.todo.md) → повторять при любых сбоях инфраструктуры; уже правило роли тимлида — без дублирования.
- Ревьювер проверяет утверждения исполнителя собственными прогонами (Пуаро: три окружения; Хаус: мутационная проверка) → ложные «зелёные» ловятся до мержа → поддерживать как норму ревью.
