## Проблемы

- **Обязательная проверка существует только вне CI:** `make phar-e2e` требует Box и исполняется только локально; в CI гоняется лишь `phar-smoke`. Регрессия E2E-асерта относительно FR-4 (#443 vs тест из #387/#400) жила около недели и вскрылась только ручным прогоном перед тегом. *(доказательство: `grep -rn "phar-e2e" .github/workflows/` — пусто; упавший тест `PharDistributionTest` в CI-задаче PR #452 отсутствует; направление: Инструменты)*
- **Liveness-gate `watch-subagent.sh` не отличает «писатель блокирован на полном FIFO» от зависания:** заблокированный в `write()` процесс имеет нулевую CPU/IO-дельту → `process_is_active()` = idle → tight stall-таймаут теста (10 с) отстреливал живой поток под нагрузкой CI. Семантика для реальных агентов намеренная; лечение — generous stall в тестах (#453). *(доказательство: `process_is_active` в `watch-subagent.sh:821-843`, повторный прогон job 125731625372 в CI зелёный без правок; направление: Инструменты)*
- **Задача перенесена в `done` после merge вместо до апрува:** `TASK-fix-phar-e2e-cache-root-auto-clean` попала в `main` со статусом `in_progress`; хвост убран PR #454 по прецеденту #450. Правило закреплено в AGENTS.md и `docs/git-workflow/pull-request.md` — нарушение исполнительское, не документное. *(доказательство: состав merge-коммита `28a4c9bb` — файл задачи в `todo/`; направление: Процессы)*
- **Находки инцидентов не зафиксированы в durable-артефактах в момент обнаружения:** первый отчёт владельцу содержал «уроки дня» только в чате; перенос в ретро/реестр выполнен лишь после явного замечания владельца. *(доказательство: сессия 2026-11-03, реплика владельца «а разве уроки дня тебя не учили фиксировать?»; направление: Процессы)*
