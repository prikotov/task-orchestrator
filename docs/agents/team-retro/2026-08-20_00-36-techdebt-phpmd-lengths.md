**Задача:** `TASK-techdebt-phpmd-lengths` (1 задача, 1 PR [#356](https://github.com/prikotov/task-orchestrator/pull/356), открыт на момент ретро)

## Что прошло хорошо

- **Полный конвейер `task-via-subagents` без пропусков:** реализация → самопроверка (подтверждение) → ревью (одобрение с замечаниями) → доработка → повторное ревью (финальное одобрение) → `make check` → 6 атомарных коммитов → PR от бота. Одна итерация доработки при лимите 3.
- **«Нулевое доверие» к отчётам сабагента (урок ретро 2026-06-30):** в этот раз расхождений не было — Левша прогнал проверки сам в полноценном окружении (включая сокетные тесты раннеров), тимлид подтвердил независимым `make check` (1496 тестов, 4003 assertions, все инструменты зелёные).
- **Пороги устранены честно:** проверка занижением порогов phpmd и прогон без baseline — нарушения сняты кодом, а не перекладыванием в baseline глубже.
- **Повторное ревью сделано точечным** (только правки по замечаниям) — дёшево и по делу.

## Проблемы

- 🟡 **Относительный путь `scripts/watch-subagent.sh` в примерах SKILL.** Первый вызов из корня проекта — `exit 127` (файла нет). Правило резолва путей от каталога скилла есть в `become-role/SKILL.md`, но сам `run-subagent/SKILL.md` его не повторяет, а примеры в нём выглядят как запуск из корня. Новая проблема (в архиве ретро не найдена). Файл: `docs/agents/skills/run-subagent/SKILL.md`.
- 🟡 **Таблица таймаутов `task-via-subagents` не учитывает `make check` в промпте.** Для C1–C2 таблица даёт 600с, но промпт конвейера требует от сабагента полный `make check` (один PHPUnit ~90с, полный набор — минуты) плюс глубокую верификацию. Сабагент-реализатор убит по soft-timeout 1200с при ~95% готовности; страховка от сжигания токенов сработала штатно, протокол Шага 3 (данные → перезапуск) отработал, но потеряны минуты и контекст. Не повтор resolved-записи «ранние таймауты и ложное убийство активных агентов» (PR #352 — про stall/liveness): здесь причина — калибровка soft-timeout под вес проверок. Файл: `docs/agents/skills/task-via-subagents/SKILL.md`.
- 🟢 **`exit 141` (SIGPIPE) у всех успешных запусков с выводом `text`.** Работа сабагентов выполнена полностью (6 запусков: 5 успешных, 1 soft-timeout), но каждый текстовый запуск фиксирует неуспешный код возврата — тот же класс шума, что `runner_failed_after_agent_end` (exit 143, ретро 2026-07-24). ⚠️ Повтор из ретро `2026-07-24_17-15-research-omp-role-delegation.md` — счётчик в реестре увеличен.
