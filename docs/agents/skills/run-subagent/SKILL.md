# Run Subagent

Делегирует задачу сабагенту в выбранной роли.

## Когда использовать

Когда нужно делегировать реализацию, ревью, доработку, тестирование или документацию.

## Вызов

`<skill-dir>` — каталог этого `SKILL.md` из `<location>`.

```bash
<skill-dir>/scripts/watch-subagent.sh -s <секунды> -r <файл-роли> [options] <<'PROMPT'
<задание сабагенту>
PROMPT
```

В задании указывай цель, путь к задаче, ожидаемый результат и ограничения. Не дублируй инструкции роли и проекта.

## Параметры

| Параметр | Сокращение | Назначение | По умолчанию |
|---|---|---|---|
| `--soft-timeout` | `-s` | Целевое время задачи в секундах; обязателен | — |
| `--hard-timeout` | `-m` | Абсолютный предел времени | 1800 |
| `--stall-timeout` | `-t` | Предел отсутствия событий для простаивающего процесса | 360 |
| `--output` | `-o` | Формат вывода: `raw`, `text`, `tools`, `files`; можно через запятую | `raw` |
| `--role-file` | `-r` | Путь к файлу роли; обязателен | — |
| `--runner` | — | `pi` или `codex` | профиль роли, иначе `pi` |
| `--provider` | — | Провайдер для `pi` | профиль роли |
| `--model` | — | Модель | профиль роли |
| `--reasoning` | — | Уровень рассуждения | профиль роли |
| `--task-id` | — | `TASK-*`, из файла которого читается сложность | — |
| `--complexity` | — | Сложность `C0–C5`; приоритет над `--task-id` | — |
| `[prompt text]` | — | Задание аргументом; без него читается из stdin | — |

Явные параметры `--runner`, `--provider`, `--model` и `--reasoning` переопределяют профиль роли. Обычно их указывать не нужно.

🔴 Обязателен хотя бы один из параметров — `--task-id` или `--complexity`: уровень выбирает командный профиль роли. Если переданы оба, действует `--complexity`. Если не передан ни один, запуск завершается ошибкой до старта агента (молчаливый дефолт `C3` удалён).

## Сложность

Один из параметров — `--task-id` или `--complexity` — обязателен: если не передан ни один, скрипт завершается с ошибкой до запуска агента. Передать оба допустимо — тогда действует `--complexity`.

- У задачи есть файл — передавай `--task-id`: уровень читается из поля `complexity` её front matter.
- Файла задачи нет (консультация, ретро, диагностика) — задавай `--complexity` явно.

Молчаливый дефолт `C3` удалён: он приводил к тому, что настроенные тиры моделей (`commands_by_complexity` в `chains.yaml`) не включались, и запуски незаметно уходили на базовый профиль.

| Уровень | Назначение |
|---|---|
| `C0` | Тривиальная правка |
| `C1` | Простая задача в одном модуле или слое |
| `C2` | Несколько компонентов или интеграций |
| `C3` | Сложная задача со множеством зависимостей |
| `C4` | Глубокая экспертиза или исследование |
| `C5` | Нерешённая проблема, требующая R&D |

## Примеры

```bash
# Выполнить задачу в роли бэкендера
<skill-dir>/scripts/watch-subagent.sh -s 600 \
  -r docs/agents/roles/team/backend_developer_levsha.ru.md \
  --task-id TASK-example <<'PROMPT'
Выполни задачу по её инструкциям. Сообщи результат и проверки.
PROMPT
```

```bash
# Получить только ответ и список изменённых файлов (файл задачи есть — берём --task-id)
<skill-dir>/scripts/watch-subagent.sh -s 600 -o text,files \
  -r docs/agents/roles/team/backend_developer_levsha.ru.md \
  --task-id TASK-example <<'PROMPT'
Выполни задачу: todo/TASK-example.todo.md. Сообщи результат и изменённые файлы.
PROMPT
```

```bash
# Провести ревью без изменения файлов (файла задачи нет — явный --complexity)
<skill-dir>/scripts/watch-subagent.sh -s 300 -o text --complexity C1 \
  -r docs/agents/roles/team/code_reviewer_backend_puaro.ru.md <<'PROMPT'
Проверь текущие изменения. Ничего не изменяй. Верни APPROVE или замечания.
PROMPT
```

## Результат

Код `0` означает успешное завершение. При ошибке изучи `run.log` и, если сохранён, каталог `events/` в `var/log/watch-subagent/<run-id>/`.

Внутреннее устройство, переменные окружения и диагностика описаны в [README.md](README.md); для обычного вызова они не нужны.
