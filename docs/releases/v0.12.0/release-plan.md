# План релиза v0.12.0

## Метаданные

- Тег: `v0.12.0`.
- Тип: `minor` — новая функциональность и несовместимость в линии `0.y`.
- База: актуальная `main` после слияния #460.
- Ветка: `release/0.12.0`.
- PR подготовки: будет указан в задаче релиза.
- Ответственный: владелец проекта.
- Плановая дата: 2026-11-06.

## Состав

- #460 — выбор команд по сложности в static, conditional и dynamic chains, упрощённый системный промпт ролей, обновление `prikotov/*`.
- Задача `TASK-update-prikotov-dependencies`.
- Подготовительный PR с `CHANGELOG.md`, этим планом и релизной задачей.

## Риски и несовместимость

- Неверная `complexity` в задаче меняет выбранный профиль; доступен явный `--complexity`.
- **Несовместимо:** resume dynamic chain требует целочисленное `complexity` (`0–5`) в `session.json`. Старые сессии без поля не поддерживаются; нужно начать новую сессию.
- Миграции данных и новые обязательные переменные окружения не требуются.

## Порядок публикации

1. Слить подготовительный PR в `main` после подтверждения владельца.
2. Проверить совпадение содержимого merge commit и одобренной вершины `release/0.12.0`.
3. Выполнить проверки и `make phar-e2e` на проверенном merge commit.
4. Создать и опубликовать только тег `v0.12.0` на проверенном merge commit.
5. Дождаться workflow `Release Phar` и проверить GitHub Release.

## Проверки перед публикацией

```bash
composer validate --strict
vendor/bin/phpunit
vendor/bin/psalm
vendor/bin/deptrac analyse --config-file=depfile.yaml --no-progress
make phar-e2e
```

Ожидаемый результат: код завершения `0`, рабочее дерево чистое.

## Проверки после публикации

- `gh release view v0.12.0 --json tagName,assets` — релиз содержит PHAR-asset.
- Workflow `Release Phar` для тега успешен.
- `git rev-list -n 1 v0.12.0` возвращает проверенный merge commit.
- Очереди и workers проектом не используются.

## Действия при проблеме

- Откат и перемещение тега не используются.
- Проблема исправляется отдельным patch release через PR.
- Ответственный: владелец проекта; координация — в задаче на исправление.
