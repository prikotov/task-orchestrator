## Порядок публикации

1. Убедиться, что PR подготовки слит в `main`, `make check` и CI зелёные.
2. Создать tag `v0.3.1` на вершине `main` и отправить его через GitHub App.
3. Дождаться workflow `Release Phar` и проверить asset (артефакт) `task-orchestrator.phar`.
4. Создать GitHub Release с заметками о составе и проверках.
5. Обновить потребляющие проекты (TasK/codexcli) до `prikotov/task-orchestrator:^0.3.1` и проверить запуск `become-role`.
