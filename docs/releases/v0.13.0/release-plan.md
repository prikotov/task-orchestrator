# План релиза v0.13.0

## Метаданные

- Тег: `v0.13.0`.
- Тип: `minor` — новая функциональность в линии `0.y`.
- База: актуальная `main` после слияния #466.
- Ветка: `release/0.13.0`.
- PR подготовки: создаётся из этой ветки.
- Ответственный: владелец проекта.
- Плановая дата: 2026-11-07.

## Состав

- #466 — резолвинг skills по упорядоченному списку каталогов: host-проект переопределяет одноимённые skills пакета и дополняет пакет своими.
- Подготовительный PR с `CHANGELOG.md`, этим планом и релизной задачей.

## Риски и несовместимость

- **Internal BC:** конструктор `YamlLoadSkillFrontmatterService` изменил аргумент `$skillsDir` → `$skillsDirs` (строка-список, разделитель «|»); сервис internal, внешних потребителей нет.
- Host-каталог `docs/agents/skills` теперь **дополняет** пакет, а не переключает его: роли, ссылающиеся на skills, отсутствующие в host-каталоге, продолжают резолвиться из пакета.
- Миграции данных и новые обязательные переменные окружения не требуются.

## Порядок публикации

1. Слить подготовительный PR в `main` после подтверждения владельца.
2. Проверить совпадение содержимого merge commit и одобренной вершины `release/0.13.0`.
3. Выполнить проверки и `make phar-e2e` на проверенном merge commit.
4. Создать и опубликовать только тег `v0.13.0` на проверенном merge commit.
5. Дождаться workflow `Release Phar` и проверить GitHub Release.

## Проверки перед публикацией

```bash
composer validate --strict
vendor/bin/phpunit
vendor/bin/psalm
vendor/bin/deptrac analyse --config-file=depfile.yaml --no-progress
make phar-e2e
```

Ожидаемый результат: код завершения `0`, рабочее дерево чистое.

## Проверки после публикации

- `gh release view v0.13.0 --json tagName,assets` — релиз содержит PHAR-asset.
- Workflow `Release Phar` для тега успешен.
- `git rev-list -n 1 v0.13.0` возвращает проверенный merge commit.

## Действия при проблеме

- Откат и перемещение тега не используются.
- Проблема исправляется отдельным patch release через PR.
- Ответственный: владелец проекта; координация — в задаче на исправление.
