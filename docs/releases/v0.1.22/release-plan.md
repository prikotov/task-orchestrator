- Линия релиза: `release/0.1`

- Ответственный: dp
- Плановая дата публикации: 2026-06-05

## Состав

- Предыдущий тег релиза: `v0.1.21`
- Включённые PR: #246
- Основные изменения:
  - добавлена сквозная проверка Phar до tag: `make phar-smoke` и `bin/phar-smoke` проверяют собранный `task-orchestrator.phar`
  - CI запускает `test` и `phar-smoke` для веток `main` и `release/**`
  - рабочий процесс `Release Phar` использует `make phar-smoke`, больше не продолжает релиз при сбое проверки и получает `permissions: contents: write` для публикации артефакта
  - обнаружение сервисов Symfony использует `%task_orchestrator.package_dir%` и исключает `src/**/Resources/`, чтобы bridge-файлы не регистрировались как сервисы в контексте Phar
  - добавлен интеграционный тест на исключение `Resources/bridge.php` из обнаружения сервисов
  - устранена первопричина серии релизов `v0.1.18`-`v0.1.21`: разные сбои сборки Phar выявлялись только после tag, потому что перед релизом не выполнялась сквозная проверка
- Вне состава релиза:
  - поведение приложения во время выполнения не меняется
  - миграции данных не требуются
  - обратно несовместимые изменения отсутствуют

## Риски

- Основные риски: низкие — изменение затрагивает операционный и релизный процесс и обнаружение сервисов Symfony для сборки Phar, а не пользовательское поведение приложения
- Наличие миграций данных: нет
- Риск окна несовместимости: нет
- Обратно несовместимые изменения: нет
