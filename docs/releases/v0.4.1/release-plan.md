## Порядок deploy

1. Merge PR подготовки релиза в `main`.
2. Опубликовать tag `v0.4.1` на merge-коммите.
3. Опубликовать GitHub Release с артефактом `task-orchestrator.phar` (сборка по `make phar-smoke`).

## Проверки после deploy

- `make check` на теге `v0.4.1` зелёный (PHPUnit + Psalm + phpcs + deptrac + validate-language).
- CI пайплайн (`test`, `composer-host-smoke`, `Phar smoke`, `scan-pr-content`) зелёный на PR #367 и после публикации тега.
- PHAR запускается: `php task-orchestrator.phar list` без ошибок.
