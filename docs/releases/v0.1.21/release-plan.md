## Состав

- Предыдущий тег рабочей версии: `v0.1.20`
- Включённые PR: #243
- Основные изменения:
  - рабочий процесс `Release Phar` использует `box compile --config=box.json.dist` вместо сборки без конфигурации
  - `box.json.dist` теперь учитывается при сборке Phar, поэтому в артефакт попадают `config/services.yaml`, `config/console_services.yaml`, `config/chains.yaml` и другие файлы из конфигурации Box
  - устранена первопричина релиза `v0.1.20`: правильный путь Phar уже использовался, но сборка через `--no-config` игнорировала `box.json.dist`; из-за отсутствия `config/services.yaml` проверочный запуск завершался с `FileLocatorFileNotFoundException`
- Вне состава релиза:
  - поведение приложения при выполнении не меняется
  - миграции данных не требуются
  - обратно несовместимые изменения отсутствуют

## Риски

- Наличие миграций данных: нет
