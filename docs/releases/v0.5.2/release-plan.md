- В правила создания навыков (`docs/agents/skills/SKILL-CREATION.md`) добавлен обязательный раздел «Скрипты и пути»: форма команды в `SKILL.md` — только стандартная относительная, резолв пути — контракт раннера, комментарий-якорь в блоке кода с командой запуска, самонастройка скриптов, покрытие тестами обоих контекстов запуска, разделение форм `SKILL.md` и документов host-проекта; удалён дублирующийся раздел «Стандарты и источники» (запрос [#374](https://github.com/prikotov/task-orchestrator/pull/374), коммит слияния `7a05979`).
- Запись реестра ретро о `watch-subagent.sh` → `exit 127` ссылается на новый раздел (#374).
- Исследование CLI-агента кодинга hax в `docs/research/` (запрос [#373](https://github.com/prikotov/task-orchestrator/pull/373), merge-коммит `272447f`).
- Код, публичный JSON/XML-контракт `agent:role-skills` и PHAR-установка `become-role` не менялись.
- Вне состава: любые изменения после подготовительного запроса релиза.

## Риски

- Состав docs-only: миграции отсутствуют, порядок применения не требуется.
- Риск окна несовместимости: низкий. Документация не влияет на runtime (исполнение) и публичные контракты.
- Обратная совместимость: публичный вывод JSON/XML команды `agent:role-skills` и поддержка `become-role` в PHAR не изменены.

## Порядок публикации

1. Убедиться, что подготовительный запрос с артефактами релиза слит в `main` и его обязательные проверки зелёные.
2. Убедиться, что `main` содержит только согласованный состав релиза: запросы #373, #374 и артефакты `v0.5.2`.
3. Выполнить `make check`, `PHAR_EXPECTED_VERSION=dev make phar-smoke`, `make composer-host-smoke` на вершине `main`.
4. Создать тег `v0.5.2` на вершине `main` и отправить его через GitHub App.
5. Дождаться сценария `Release Phar`: он автоматически создаёт GitHub Release и загружает файл `task-orchestrator.phar`.
6. Проверить автоматически созданный GitHub Release; при необходимости обновить заметки через `gh release edit`.
7. Проверить опубликованный PHAR командой `php task-orchestrator.phar list`.

## Проверки перед публикацией

- [ ] Подготовительный запрос слит в `main`; непрерывная интеграция зелёная.
- [ ] `make check` успешно выполнен на вершине `main`.
- [ ] `PHAR_EXPECTED_VERSION=dev make phar-smoke` и `make composer-host-smoke` успешно выполнены до публикации тега.
- [ ] Тег `v0.5.2` отсутствует до публикации.
- [ ] В `main` присутствуют запись `CHANGELOG.md`, план `v0.5.2` и завершённая задача подготовки release PR.

## Проверки после публикации

- [ ] Выпуск GitHub содержит тег `v0.5.2` и `task-orchestrator.phar`.
- [ ] `git describe --tags` на `main` показывает `v0.5.2`.
- [ ] PHAR запускается: `php task-orchestrator.phar list`.
- [ ] Публичный вывод JSON/XML команды `agent:role-skills` остаётся совместимым (состав релиза docs-only).
